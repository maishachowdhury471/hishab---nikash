# AI Hisab Nikash — স্মার্ট হিসাব (Railway-ready)

দৈনন্দিন আয়-ব্যয়ের হিসাব রাখার ওয়েবসাইট। সম্পূর্ণ বাংলা (বাংলা/English টগল সহ),
AI দ্রুত লিখন (টাইপ বা ভয়েস), মাসের সারসংক্ষেপ, গত মাসের সাথে তুলনা, AI পরামর্শ
এবং বেশি খরচের সতর্কতা। কোনো নমুনা ডেটা নেই — শুরু থেকে খালি।

**Stack:** Python FastAPI (একটাই সার্ভিস — API + স্ট্যাটিক ফ্রন্টএন্ড), PostgreSQL
(Railway), SQLite ফলব্যাক (লোকাল ডেভ), SQLAlchemy (sync, `psycopg` ড্রাইভার),
সাদা HTML/JS + Tailwind CDN (কোনো npm build নেই), PWA (manifest + service worker)।

## Railway-তে লাইভ করার ধাপ (সঠিক ক্রম)

1. **কোড GitHub-এ তুলুন** — এই ফোল্ডারের সব ফাইল একটি GitHub রিপোজিটরিতে push করুন
   (যেমন `hisab-nikash`)।
2. **Railway-তে যান** — https://railway.app → **New Project → Deploy from GitHub repo**
   → ওই রিপোজিটরি বেছে নিন।
3. **PostgreSQL যোগ করুন** — প্রজেক্টে **+ New → Database → Add PostgreSQL**।
4. **ডাটাবেস লিংক করুন** — Postgres সার্ভিসে গিয়ে **Variables** থেকে
   `DATABASE_URL` কপি করুন; ওয়েব সার্ভিসের **Variables**-এ `DATABASE_URL` হিসেবে
   বসান (সাধারণত Railway নিজেই reference হিসেবে দেয়:
   `DATABASE_URL=${{Postgres.DATABASE_URL}}`)।
   > `DATABASE_URL` না দিলে অ্যাপ SQLite ফাইলে চলবে, কিন্তু Railway-তে ফাইল
   > স্থায়ী নয় — তাই Postgres অবশ্যই লিংক করুন।
5. **Deploy** — Railway নিজেই `Dockerfile` ধরে build করে deploy করবে
   (`railway.toml` দেখুন)। Deploy শেষ হলে **Settings → Networking → Generate Domain**
   চাপুন।
6. **খুলুন** — দেওয়া URL (যেমন `https://hisab-nikash.up.railway.app`) ব্রাউজারে
   খুলুন। প্রথম পাতায় “হিসাব” দেখা গেলেই লাইভ।

## লোকালে চালানো

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# SQLite (ডিফল্ট): DATABASE_URL না দিলেই চলবে; hisab.db ফাইল তৈরি হবে।
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
# অথবা Postgres: DATABASE_URL=postgresql+psycopg://user:pass@localhost:5432/hisab uvicorn ...
```

ব্রাউজারে খুলুন: http://localhost:8000

## টেস্ট

```bash
cd backend
python -m pytest tests/ -v
```

টেস্টে অস্থায়ী SQLite DB ব্যবহার হয় — আসল `hisab.db` ছোঁয় না।

  শিশুর খরচ, খেলাধুলা, অন্যান্য।
  আয়ের খাত (১৬টি): বেতন, ব্যবসা, ফ্রিল্যান্সিং, টিউশন/পড়ানো,
  কৃষি আয়/ফসল বিক্রি, বাড়ি/দোকান ভাড়া আয়, সুদ/লভ্যাংশ, বোনাস,
  উপহার/সালামি, রেমিট্যান্স/বিদেশ থেকে, অনলাইন আয়, পার্ট টাইম, কমিশন,
  পুরনো জিনিস বিক্রি, ঋণ ফেরত, অন্যান্য আয়। দিন অনুযায়ী গ্রুপ করা তালিকা + মোট।
- **মাস নির্বাচন:** আগের/পরের মাস বোতাম + মাস ইনপুট। খাত অনুযায়ী বার চার্ট।
- **তুলনা:** এই মাস বনাম গত মাস — আয়/খরচ/সঞ্চয় কার্ড (+% পরিবর্তন) এবং
  খাতভিত্তিক টেবিল (এই মাস, গত মাস, পার্থক্য)।
- **AI দ্রুত লিখন:** লিখুন বা মাইকে বলুন (Web Speech API, `bn-BD`/`en-US`)।
  সার্ভার `POST /api/parse` পার্স করে ফরমে **বসিয়ে দেয় — কখনো নিজে সংরক্ষণ করে না**,
  ব্যবহারকারী যাচাই করে Save চাপেন। যাচাই করা উদাহরণ:
  - “আজ বাজারে ৫০০ টাকা খরচ” → খরচ ৳৫০০, বাজার, আজ
  - “গতকাল রিকশা ভাড়া ৮০ টাকা” → খরচ ৳৮০, যাতায়াত, গতকাল
  - “বেতন পেলাম ৩০০০০ টাকা” → আয় ৳৩০,০০০, বেতন
  - “বাড়ি ভাড়া দিলাম ১০০০০ টাকা” → খরচ ৳১০,০০০, বাড়ি ভাড়া — আর
    “বাড়ি ভাড়া পেলাম ২০০০০ টাকা” → আয় ৳২০,০০০, বাড়ি/দোকান ভাড়া আয়
  - “বিদ্যুৎ বিল দিলাম ১৫০০ টাকা” → খরচ ৳১,৫০০, বিদ্যুৎ বিল
  - “টিউশন ফি পেলাম ৫০০০ টাকা” → আয় ৳৫,০০০, টিউশন/পড়ানো
  - “ফ্রিল্যান্সিং থেকে পেলাম ১৫০০০ টাকা” → আয় ৳১৫,০০০, ফ্রিল্যান্সিং
  বাংলা সংখ্যাও চলে (৫০০ → 500)।
- **AI পরামর্শ:** মাসের আসল মোট বনাম গত মাস থেকে নিয়মভিত্তিক (deterministic)
  ২–৪টি পরামর্শ — সবচেয়ে বড় খাত + অংশ, সবচেয়ে বেশি বেড়ে যাওয়া খাত, সঞ্চয়।
- **বেশি খরচের সতর্কতা:** কোনো খাত গত মাসের চেয়ে **৩০%-এর বেশি** বাড়লে সতর্কতা
  ব্যাজে খাতের নাম ও % দেখায়।
- **ভাষা:** সম্পূর্ণ বাংলা প্রথম, বাংলা/English টগল (পছন্দ localStorage-এ থাকে);
  বাংলা মোডে বাংলা সংখ্যা (০১২৩৪৫৬৭৮৯), English মোডে লাতিন সংখ্যা।
- **প্রতিদিনের হিসাবের রিমাইন্ডার (নোটিফিকেশন):** শেষ হিসাবের পর ১ দিনের বেশি
  পার হলে (কোনো একটা পুরো দিন হিসাব ছাড়া গেলে) সকাল ৯টায় (Asia/Dhaka)
  নোটিফিকেশন আসে — “আজকের হিসাব কি লিখেছো? আজকের দিনটাও তোমার দৈনন্দিন
  হিসাবের মধ্যে পড়ে — এখনই অ্যাপে ঢুকে আজকের খরচ বা আয় লিখে ফেলো।”
  দিনে একটার বেশি রিমাইন্ডার যায় না (de-dup)। অ্যাপের ভেতরে “প্রতিদিনের
  হিসাবের রিমাইন্ডার” কার্ড থেকে “রিমাইন্ডার চালু করো” চাপলে ব্রাউজার
  নোটিফিকেশনের অনুমতি চায়; ছুটে যাওয়া দিনের তালিকা আর “আজকের হিসাব লিখুন”
  বোতাম সেখানেই দেখায়। প্রতিটি রিমাইন্ডারের ইতিহাস থাকে — কখন আসার কথা ছিল
  (exact সময়, যেমন “১৯ নভেম্বর ২০২৬, সকাল ৯:০০”) আর কতক্ষণ আগে এসেছে
  (“৩ ঘণ্টা আগে” / “২ দিন আগে”) — সময়ের সাথে সাথে আপডেট হয়।
  সার্ভার পুশের জন্য VAPID কী লাগে (নিচে “রিমাইন্ডার সেটআপ” দেখুন)।
- **PWA:** `manifest.json` (নাম “AI Hisab Nikash”, theme `#047857`), আইকন
  (`icon.svg`, `icon-192.png`, `icon-512.png`), `sw.js` অ্যাপ শেল ক্যাশ করে।

## রিমাইন্ডার সেটআপ (VAPID কী + প্রতিদিনের ট্রিগার)

সার্ভার থেকে পুশ নোটিফিকেশন পাঠাতে দুটো জিনিস লাগে — দুটোই একবার করলেই হবে:

1. **VAPID কী বানান** (একবার):
   ```bash
   python scripts/gen_vapid_keys.py
   ```
   যে দুটো লাইন ছাপবে, সেগুলো Railway-তে ওয়েব সার্ভিসের **Variables**-এ বসান:
   `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`। সাথে `VAPID_SUBJECT` দিন
   (যেমন `mailto:maisha@example.com`)। প্রাইভেট কী কাউকে দেবেন না, Git-এ
   তুলবেন না। কী ছাড়াও অ্যাপ চলবে — তখন শুধু সার্ভার পুশ বন্ধ থাকবে, অ্যাপের
   ভেতরের রিমাইন্ডার আর ক্যাচ-আপ ঠিকই কাজ করবে।
2. **একটা লম্বা গোপন কথা (secret) বানান** — যেকোনো লম্বা এলোমেলো লেখা, যেমন
   `hn-remind-9f3k2...`। Railway Variables-এ `REMINDER_SECRET` হিসেবে বসান।
   এটা ছাড়া ট্রিগার কাজ করবে না (503 আসবে)।
3. **প্রতিদিনের ট্রিগার — cron-job.org (ফ্রি):** Railway-এর ফ্রি প্ল্যানে
   নিজে থেকে সময়মতো চালানোর (cron) ব্যবস্থা নেই, তাই বাইরের ফ্রি সার্ভিস
   দিয়ে ডাকতে হয়:
   - https://cron-job.org-এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন → **Create cronjob**।
   - **Title:** `Hisab Nikash daily reminder`
   - **URL:** `https://<আপনার-railway-ডোমেইন>/api/reminders/trigger`
     (যেমন `https://hishab-nikash-production.up.railway.app/api/reminders/trigger`)
   - **Request method:** POST
   - **Schedule:** প্রতিদিন **09:00**, টাইমজোন **Asia/Dhaka**
     (ঐচ্ছিকভাবে আরেকটা 21:00-তেও বসাতে পারেন — দিনে একবারের বেশি
     রিমাইন্ডার যাবে না, de-dup আছে)।
   - **Headers:** একটা হেডার যোগ করুন — নাম `X-Reminder-Secret`, মান
     আপনার `REMINDER_SECRET`-এর মান (ধাপ ২-এর গোপন কথাটা)।
   - **Save** চাপুন, তারপর **Run now / Test** দিয়ে পরীক্ষা করুন — হিসাব
     ১ দিনের বেশি পুরনো হলে `{"due": true, ...}` আসবে, নাহলে
     `{"due": false, "sent": 0}`।
   - ভুল secret দিলে 401 আসবে, secret না বসানো থাকলে 503 আসবে।
4. **ফোনে চালু করা:** অ্যাপ খুলে “প্রতিদিনের হিসাবের রিমাইন্ডার” কার্ডে
   **“রিমাইন্ডার চালু করো”** চাপুন → ব্রাউজারের অনুমতির বাক্সে **Allow**
   চাপুন। ব্যস — এরপর থেকে ১ দিনের বেশি হিসাব না লিখলে সকাল ৯টায়
   নোটিফিকেশন আসবে।

## সীমাবদ্ধতা (সত্য কথা)

- **রিমাইন্ডার ও অফলাইন — সত্য কথাটা:** PWA হিসেবে এই অ্যাপ **ঠিক সময়ে
  নোটিফিকেশন দিতে পারে না** যখন ফোনের Chrome পুরোপুরি বন্ধ/force-stop থাকে
  আর ইন্টারনেটও নেই — স্থিতিশীল Chrome-এ Notification Triggers নেই,
  Periodic Sync কমপক্ষে ~১২ ঘণ্টা পর পর আর ব্রাউজারের ইচ্ছেমতো চলে। এটা
  কোনো কোড দিয়ে ঠিক করা যায় না, অ্যাপেও এই কথাটা পরিষ্কার লেখা আছে।
  তাই ব্যবস্থাটা তিন স্তরে: (১) ফোন অনলাইনে থাকলে সার্ভার পুশ (cron
  ট্রিগার) অ্যাপ বন্ধ থাকলেও নোটিফিকেশন পাঠায়; (২) অ্যাপ খোলা থাকলে বা
  Chrome ব্যাকগ্রাউন্ডে বেঁচে থাকলে লোকাল চেক চলে; (৩) **ক্যাচ-আপ —
  সবচেয়ে নির্ভরযোগ্য অংশ:** অফলাইনে থাকতে যে রিমাইন্ডার আসেনি, অ্যাপ
  খুললেই বা ইন্টারনেট ফিরলেই (Background Sync-সহ) সেটি **আসল সময়সহ**
  (“আসার কথা ছিল ১৯ নভেম্বর, সকাল ৯টা — ২ দিন আগে”) দেখিয়ে দেওয়া হয়।
  আর অফলাইনে অ্যাপ খুললে ছুটে যাওয়া দিনের কার্ডটি এমনিতেই দেখায় — এতে
  ইন্টারনেট লাগে না।
- **অফলাইন:** `sw.js` অ্যাপের চেহারা (UI) ক্যাশ করে, তাই অফলাইনে অ্যাপ খুলে দেখা
  যায়। কিন্তু হিসাব সার্ভারের ডাটাবেসে (PostgreSQL) থাকে, তাই **নতুন হিসাব
  সংরক্ষণে ইন্টারনেট লাগবেই** — অফলাইনে লেখা হিসাব সার্ভারে যাবে না।
- **ভয়েস:** মাইক বোতাম শুধু Web Speech API সমর্থন করে এমন ব্রাউজারে দেখায়
  (Chrome/Android); না থাকলে বোতাম লুকানো থাকে, টাইপ করে লেখা যায়।
- **AI:** কোনো বাইরের AI API ব্যবহার হয় না — পার্সার ও পরামর্শ দুটোই
  নিয়মভিত্তিক (rule-based), তাই সম্পূর্ণ বিনামূল্যে ও অফলাইন-নিরাপদ।

## API

| Method | পথ | কাজ |
|---|---|---|
| GET | `/api/health` | `{"status":"ok"}` |
| GET | `/api/entries?month=YYYY-MM` | মাসের হিসাবের তালিকা |
| POST | `/api/entries` | নতুন হিসাব (`type`, `amount>0`, `category`, `note`, `date`) |
| PUT | `/api/entries/{id}` | হিসাব আপডেট |
| DELETE | `/api/entries/{id}` | হিসাব মুছুন |
| GET | `/api/summary?month=YYYY-MM&lang=bn\|en` | মোট, খাতভিত্তিক, তুলনা, overspend, পরামর্শ |
| POST | `/api/parse` | `{text}` → `{type, amount, category, note, date}` |
| GET | `/api/config` | VAPID public key + `push_enabled` + রিমাইন্ডারের সময় (সকাল ৯টা) |
| POST | `/api/push/subscribe` | `{device_id, subscription}` — পুশ সাবস্ক্রিপশন সংরক্ষণ |
| POST | `/api/push/unsubscribe` | `{endpoint}` বা `{device_id}` — সাবস্ক্রিপশন মুছুন |
| GET | `/api/reminders/status` | শেষ হিসাবের তারিখ, ছুটে যাওয়া দিন, due কিনা, `due_at` |
| GET | `/api/reminders/history` | পাঠানো/দেখানো রিমাইন্ডারের তালিকা — exact `due_at` + `sent_at` |
| POST | `/api/reminders/trigger` | প্রতিদিনের cron ট্রিগার — হেডার `X-Reminder-Secret: <REMINDER_SECRET>` |
| POST | `/api/reminders/shown` | `{device_id, due_at, channel}` — লোকালে দেখানো রিমাইন্ডার ইতিহাসে লেখা |

ফ্রন্টএন্ড `/`-এ, manifest `/manifest.json`-এ, service worker `/sw.js`-এ।
